## Purpose

How EnclaveStack looks, across the console (this repo) and the public website (`marketing`). Under the org topology (`L0-010`) the brand palette and mark are owned by `assets`; that repo holds nothing yet, so this document is the working copy until it does — then `assets` becomes the source and this document follows it. Code reads these values from one token file per app — never inline literals.

## 1 · Direction

Quiet, technical, confident. A cool off-white ground, near-black ink, one electric-blue accent. Monospace for anything a machine would print (hostnames, engines, commands). Motion is purposeful: cards fan out, toasts slide in; everything respects `prefers-reduced-motion`.

**No eyebrow labels.** Headings and cards never carry a small label above them (a pill like "open source · self-hosted cloud", a mono tag like "compute", a step number like "01 · install"). A heading stands on its own; supporting detail goes below it or in the card's footer line.

## 3 · Accessibility

Body text ≥ 4.5:1 against its ground in both themes; status is never colour alone (always a word beside the dot); touch targets ≥ 44 px; every control is a real `<button>`, `<a>` or `<input>` with a label.

## 5 · Console shape language (v3)

Founder decision (2026-10-20): the console follows the layout and shape language of the Tandem template the founder chose as inspiration, **keeping EnclaveStack's palette** (cool off-white ground, near-black ink, electric-blue accent). We take the look, not the code: everything is our own markup and CSS.

| Element | Rule |
|---|---|
| Type | **Plus Jakarta Sans** (400–800) in the console; IBM Plex Mono for machine text. The public website keeps Schibsted Grotesk. Base size 14 px; detail title 34 px / 800; panel titles 26 px. |
| Radii | `--es-r-sm` 12 · `--es-r-md` 16 · `--es-r-lg` 22 · `--es-r-xl` 28; buttons, chips and inputs are full pills (`999px`). |
| Surfaces | The sidebar sits on the page ground (no dark rail). The list and the detail are rounded panels (`--es-r-xl`) with a hairline border; items inside are white cards (`--es-r-lg`). |
| Selection | The selected nav item and list card fill with `--es-accent-soft`; the nav icon turns `--es-accent`. |
| Header wash | The detail panel's top carries a soft radial wash of the accent (`--es-wash`), fading to the surface. |
| Avatars | Resources show a round avatar with their initials on one of six pastel tones chosen from the name (`--es-av-1…6`). |
| Buttons | Primary action: dark pill (`--es-act` on `--es-on-act`). Secondary: outlined pill. Icon buttons: 40 px circles. |
| Progress | Provisioning steps render as a segmented pill with numbered circles; done steps fill with the accent. |
| Tabs | Segmented control: the active tab is a dark pill. |

Implementation: every value above lives in `packages/ui/src/tokens.css` and nowhere else (ADR-014).

## 6 · Chart series (v4)

Metrics charts (L2.5-002 §14) colour lines by their order, from eight tokens `--es-series-1` … `--es-series-8`. The order is the colour-blind-safety mechanism, not decoration: it was checked with a palette validator against EnclaveStack's own chart surfaces (`#FFFFFF` light, `#181D1B` dark) and passes every hard check in both themes (worst neighbouring pair ΔE 9.1 for colour-blind readers in light, 8.4 in dark; normal vision 19.6 / 19.3).

| Slot | Light | Dark |
|---|---|---|
| 1 blue | `#2A78D6` | `#3987E5` |
| 2 orange | `#EB6834` | `#D95926` |
| 3 aqua | `#1BAF7A` | `#199E70` |
| 4 yellow | `#EDA100` | `#C98500` |
| 5 magenta | `#E87BA4` | `#D55181` |
| 6 green | `#008300` | `#008300` |
| 7 violet | `#6250D6` | `#9085E9` |
| 8 red | `#E34948` | `#E66767` |

Rules: never cycle or generate a ninth colour (a dashboard widget takes at most eight resources; a chart names the series it can't draw); text stays in ink tokens, never the series colour; slots 3, 4 and 5 are under 3:1 on white, so every chart has a legend with values in text and a hidden table. Status colours (`--es-ok`, `--es-warn`, `--es-bad`) are never used for series.
